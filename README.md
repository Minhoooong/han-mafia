# 흑야 — 한국어 웹 마피아

설치와 회원가입 없이 방 코드를 공유해 즐기는 5–12인 실시간 웹 마피아 게임입니다.

## 주요 기능

- 5자리 방 코드 생성 및 참가
- 실시간 대기실·채팅·밤 행동·투표
- 마피아·시민·경찰·의사 역할
- 역할 및 수사 결과 비공개 전송
- 승리 조건 자동 판정
- 모바일·PC 반응형 다크 UI
- 별도 관리자 테스트 서버와 자동 테스트봇

## 일반 게임 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:7860`으로 접속합니다.

## 관리자 기능 테스트

일반 게임과 분리된 테스트 서버를 실행합니다.

```bash
npm run test:admin
```

브라우저에서 다음 주소로 접속합니다.

```text
http://localhost:7861/admin-test.html
```

관리자 테스트 화면에서 다음 기능을 사용할 수 있습니다.

- 테스트봇 5명 자동 충원
- 역할 자동 배정 및 전체 역할 확인
- 밤 행동과 투표 자동 입력
- 밤·새벽·토론·투표·결과 단계 강제 이동
- 개별 플레이어 사망·부활 처리
- 게임 상태 초기화 및 새 테스트방 생성

관리자 테스트 서버는 일반 게임 서버와 다른 포트에서 실행되므로 실제 사용자 방에는 영향을 주지 않습니다. 외부 공개 배포용이 아니라 로컬 기능 검증용입니다.

## 배포

Docker, Render, Railway 설정이 포함되어 있습니다. 일반 서버 상태 확인 경로는 `/health`입니다.

현재 방 상태는 서버 메모리에 저장되므로 서버가 재시작되면 진행 중인 방은 사라집니다.
