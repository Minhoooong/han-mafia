# 흑야 — 한국어 웹 마피아

설치와 회원가입 없이 방 코드를 공유해 즐기는 5–12인 실시간 웹 마피아 게임입니다.

## 주요 기능

- 5자리 방 코드 생성 및 참가
- 실시간 대기실·채팅·밤 행동·투표
- 마피아·시민·경찰·의사 역할
- 역할 및 수사 결과 비공개 전송
- 승리 조건 자동 판정
- 모바일·PC 반응형 다크 UI

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:7860`으로 접속합니다.

## 배포

Docker, Render, Railway 설정이 포함되어 있습니다. 상태 확인 경로는 `/health`입니다.

현재 방 상태는 서버 메모리에 저장되므로 서버가 재시작되면 진행 중인 방은 사라집니다.
